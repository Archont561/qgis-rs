## Why qgis-rs?

<CardGrid stagger>
  <Card title="Native performance" icon="rocket">
    Render QGIS projects at C++ speed with no Python overhead — batch-process
    thousands of maps in minutes.
  </Card>
  <Card title="Type safety" icon="approve-check">
    Catch errors at compile time instead of at render time.
  </Card>
  <Card title="Full QGIS styling" icon="puzzle">
    Reuse existing `.qgs` projects, symbology, labels, and print layouts.
  </Card>
  <Card title="Zero-cost abstractions" icon="setting">
    Safe wrappers with no runtime overhead over the QGIS C++ API.
  </Card>
</CardGrid>
