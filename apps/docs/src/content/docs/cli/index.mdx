# qgis-cli

The `qgis-cli` binary provides command-line access to qgis-rs rendering and serving capabilities.

## Commands

| Command | Description |
|---------|-------------|
| [`render`](/cli/render) | Render a QGIS project to an image |
| [`tiles`](/cli/tiles) | Generate tile pyramids |
| [`batch`](/cli/batch) | Batch render multiple extents |
| [`info`](/cli/info) | Inspect a QGIS project |
| [`serve`](/cli/serve) | Start an HTTP map server |
| [`export`](/cli/export) | Export features from a layer |
| [`mcp`](/cli/mcp) | Serve the same capabilities as an MCP server for AI assistants |

:::note
`qgis-cli` is the command-line front end for the `qgis-render` and
`qgis-server` crates. Each subcommand maps onto a module in the
[API Reference](/reference/) — `render` onto [`render`](/reference/render),
`tiles` onto [`tiles`](/reference/tiles), `export` onto
[`features`](/reference/features), and `serve` onto
[`server`](/reference/server).
:::

## Installation

```bash
cargo install qgis-cli
```

Or build from source:

```bash
cargo build --release -p qgis-cli
```

## Quick Examples

```bash
# Render a project
qgis-cli render map.qgs -o map.png

# Generate tiles
qgis-cli tiles map.qgs -z 10-14 -b 14,50,15,51 -o ./tiles/

# Start a server
qgis-cli serve map.qgs --port 8080

# Inspect a project
qgis-cli info map.qgs

# Serve the same capabilities to an MCP client over stdio
qgis-cli mcp
```
