# Plugin SDK — qgis-sdk

`qgis-sdk` is a **pure-Python** framework for building QGIS plugins on top of PyQGIS, with a `qgis-sdk` CLI built on [typer](https://typer.tiangolo.com). It ships no native code and needs no Rust toolchain; install it from pip or conda-forge.

- **pip**: `pip install qgis-sdk` → `import qgis_sdk` + the `qgis-sdk` console script on PATH
- **conda**: `conda install -c conda-forge qgis-sdk` → same, with QGIS backend

`qgis-rs` (rendering/tiling) is a separate distribution and can be installed alongside. The two are independent: `qgis-rs` is the Rust engine client and `qgis-sdk` is pure Python, and the SDK does not import `qgis_py`.

## Installation

```bash
pip install qgis-sdk
# or
conda install -c conda-forge qgis-sdk
pixi add qgis-sdk

# Test
python -c "import qgis_sdk; print(qgis_sdk.__version__)"
qgis-sdk --help
qgis-sdk version
```

From source:

```bash
git clone https://github.com/Archont561/qgis-rust
cd qgis-rs
pip install -e ./py-packages/qgis-sdk
python -m pytest py-packages/qgis-sdk/tests -v
```

## Python API

```python
from qgis_sdk import Plugin, action, toolbar, menu

class MyPlugin(Plugin):
    name = "My Plugin"
    version = "0.1.0"
    description = "Does useful things"
    author = "Your Name"
    email = "you@example.com"
    qgis_min_version = "3.28"
    category = "Vector"

    @toolbar("My Toolbar")
    @action(tooltip="Run my tool", icon="icons/tool.svg")
    def run_tool(self, iface):
        layer = iface.activeLayer()
        print(layer.name(), layer.featureCount())

    @menu("Plugins", "My Plugin", "Settings")
    def open_settings(self, iface):
        ...

# metadata.txt generation
print(MyPlugin.metadata_txt())
MyPlugin.write_metadata("./my_plugin")
```

Processing algorithm:

```python
from qgis_sdk import Algorithm, parameter, output

class BufferAdvanced(Algorithm):
    id = "my_plugin:buffer_advanced"
    name = "Advanced Buffer"
    group = "Vector geometry"

    input_layer = parameter.source("Input layer")
    distance = parameter.distance("Buffer distance", default=10.0)
    dissolve = parameter.boolean("Dissolve results", default=False)
    output_layer = output.sink("Buffered")

    def process(self, context):
        distance = context.get(self.distance)
        # ...
        return {self.output_layer.name: distance}
```

## CLI — pure Python

```bash
# Scaffold
qgis-sdk new my_plugin --type processing
qgis-sdk new my_plugin --author "Your Name" --email "you@example.com"

# Validate
qgis-sdk validate
qgis-sdk validate ./my_plugin
qgis-sdk info ./my_plugin --json

# Build, test, install
qgis-sdk build
qgis-sdk test
qgis-sdk install
qgis-sdk dev --launch

# Package for QGIS Plugin Repository
qgis-sdk package -o dist/
qgis-sdk publish --zip dist/my_plugin-0.1.0.zip --dry-run

# Same CLI via Python
python -m qgis_sdk.cli new my_plugin
python -m qgis_sdk.cli validate
qgis-sdk version  # alias
```

## Architecture

```
qgis-sdk wheel
├── qgis_sdk/
│   ├── __init__.py       → Python API (Plugin, Algorithm, metadata)
│   ├── cli.py            → typer CLI (`qgis-sdk`); questionary prompts for UI scaffolding
│   ├── plugin_validation.py → `qgis-sdk validate` rules
│   ├── plugin.py         → Plugin base class
│   ├── algorithm.py      → Algorithm base class
│   └── runtime.py        → lazy PyQGIS access
└── qgis_sdk-*.dist-info/entry_points.txt
                          → `qgis-sdk` console script → `qgis_sdk.cli:main`
```

There is no `bin/` directory and no binary: the wheel is pure Python, and
`qgis-sdk` reaches `PATH` as a console script declared under
`[project.scripts]` in `pyproject.toml`.

- Python: `src/qgis_sdk/` with `pyproject.toml` using the setuptools backend; no native code
- Conda: `recipes/qgis-sdk/meta.yaml` pip-installs the same pure-Python package and declares the same `qgis-sdk = qgis_sdk.cli:main` entry point

### Testing without QGIS

`qgis_sdk.testing` provides fakes + pytest fixtures:

```python
# tests/conftest.py
pytest_plugins = ["qgis_sdk.testing"]

def test_toolbar(fake_iface, fake_action_factory):
    from my_plugin import MyPlugin
    MyPlugin.action_factory = staticmethod(fake_action_factory)
    plugin = MyPlugin(fake_iface)
    plugin.init_gui()
    assert len(fake_iface.toolbar_icons) == 1

def test_bridge(fake_bridge):
    assert fake_bridge.get_layer()["name"] == "test_layer"
```

Fakes: `FakeIface`, `FakeAction`, `FakeDialog`, `FakeWebView`, `FakeBridge`, `mock_features()`, `mock_source()`.

```bash
python -m pytest py-packages/qgis-sdk/tests -q  # 112 tests, no QGIS
```

See [Testing Fixtures Guide](/guides/testing-fixtures/).
